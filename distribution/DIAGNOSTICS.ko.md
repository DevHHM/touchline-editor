# 오류 기록과 공개 오류 보고

0.14.0부터 연결 실패, 엔진 실행·종료, 연결 상태 변화, 예외를 순환 로그로 기록합니다.
도움말 → 진단에서 로그 폴더 열기와 진단 ZIP 내보내기를 사용할 수 있습니다.
연결 오류 화면에서도 같은 기능을 제공합니다.

## 공개 GitHub 오류 수집

오류가 발생하면 공개 GitHub에 해당 오류 요약을 공유할지 먼저 묻습니다.
기본 선택은 **공유 안 함**이며, 닫기·Esc·동의창 실패도 공유하지 않은 것으로 처리합니다.
**이 오류 공유**를 직접 눌렀을 때 그 보고서만 보냅니다. 앞으로 발생할 오류까지 자동 동의하는 설정은 없습니다.
동일 오류의 동의창은 실행 중 한 번만 표시하며, 다른 앱을 사용하는 동안에는 에디터로 돌아올 때까지 기다립니다.
서버가 설정되지 않은 배포본은 공유를 요청하거나 전송하지 않습니다.

동의한 오류 보고는 Cloudflare 수집 서버를 거쳐
https://github.com/DevHHM/touchline-editor/issues 에 공개될 수 있습니다.
같은 에디터 버전과 오류 코드는 묶어서 처리합니다.
같은 오류가 다시 접수되면 기존 이슈의 집계 영역을 갱신합니다.
오류별 갱신은 최대 시간당 1회이며, 서버 전체는 하루 새 이슈 생성 시도 5회·집계 갱신 시도 20회로 제한합니다.
집계 수는 접수 건수이며 고유 사용자 수가 아닙니다.

전송 필드는 에디터 버전, 발생 시각, 오류 분류 코드, 원천(client/engine),
사전에 허용한 이벤트명, 확인 가능한 경우 지원 빌드 식별자, 임의의 보고 ID뿐입니다.
오류 원문·스택·사용자 이름·개인 경로·선수 정보·검색 내용·세이브·메모리 덤프·API 토큰·원본 로그는 전송하지 않습니다.
네트워크 요청을 처리하는 Cloudflare에는 접속 IP가 전달됩니다. 서버는 남용 방지를 위한 일일 해시로만 사용하고 GitHub 이슈에는 포함하지 않습니다.

사용자 측 전송은 하루 최대 20건이며, 대기 파일은 최대 32건입니다.
같은 오류는 하루에 한 번만 전송합니다. 대기 보고는 7일이 지나면 폐기합니다.
서버가 접수를 확인하지 않으면 **그 보고서에 이미 동의한 경우에만** 대기 상태를 유지하고 5분 이상 뒤 재시도합니다.
도움말 → 진단의 **이번 실행 공유 중지 · 대기 보고 삭제**는 현재 전송과 동의창을 취소하고, 대기 보고를 삭제하며 현재 실행의 추가 공유를 막습니다.
설정 파일을 읽거나 저장할 수 없어도 현재 실행의 전송은 즉시 막습니다. 해제 상태 저장 실패 시 다음 실행의 상태를 확인하도록 안내합니다.
전송 주소·개인정보 안내 주소·공개 범위가 바뀌면 기존 동의는 무효이며, 이전 자동 공유 방식의 동의도 이어받지 않습니다.
이미 접수·공개된 보고는 공유를 중지해도 취소되거나 GitHub에서 삭제되지는 않습니다.

## 로컬 진단 ZIP

로그 폴더는 `%LOCALAPPDATA%\TouchlineEditor\Logs`입니다.
원래 요청의 인자나 응답 데이터는 기록하지 않으며 개인 경로·주소·토큰을 가립니다.
파일당 약 256KiB, 실행 세션당 4개를 순환 사용합니다.
종료된 로그는 원천별 합계 약 5MiB 또는 7일 기준으로 정리하며, 다른 실행 중인 에디터의 로그는 건드리지 않습니다.

ZIP에는 검증된 진단 로그와 버전·실행 환경 정보만 포함합니다.
ZIP 내보내기는 업로드가 아닙니다. 공개 이슈에 첨부하기 전에는 내용을 확인하세요.
과거 버전의 원본 오류 파일이나 다른 폴더의 파일은 자동으로 포함하지 않습니다.

## 배포 설정

`app/diagnostics-collector.json`에는 배포자가 검증한 HTTPS 수집 주소·안내 주소만 넣습니다.
GitHub 토큰이나 Cloudflare 인증키를 이 파일 또는 에디터 배포 ZIP에 넣으면 안 됩니다.
수집 서버 코드와 배포 절차는 소스의 `services/diagnostics-collector`에 있습니다.
