# Touchline Editor 0.14.4 — 종합 실시간 에디터

처음 사용하는 분을 위한 짧은 안내를 추가한 공개 테스트판입니다.
0.14.3의 검색·관심명단·최근 기록·오류 공유·업데이트 기능을 포함합니다.

## 처음 시작하기

- 첫 실행에 연결 → 검색 → 변경 검토 → 기록·도움말을 4단계로 안내합니다.
- 이전·다음으로 이동하고, 완료하거나 건너뛰면 다음 실행부터 자동 표시하지 않습니다.
- 오른쪽 위 ? → **처음 시작하기 · 안내 다시 보기**에서 언제든 다시 볼 수 있습니다.
- 작은 창과 글자 확대 시에도 안내와 버튼에 접근할 수 있습니다.
- 안내 중 자동 업데이트 알림이 겹쳐 열리지 않도록 했습니다.

안내는 FM에 연결하거나 게임을 수정하지 않습니다. 오류 보고는 기존과 같이
**해당 오류에 사용자가 동의한 경우에만** 공개 GitHub 이슈로 전송됩니다.

## 배포

ZIP 전체를 새 폴더에 풀고 최상위 **Touchline Editor.exe**를 실행하세요.
별도 .NET·브라우저 설치는 필요 없습니다. app/·engine/ 폴더를 함께 유지하세요.
자동 업데이트에서 이 공개 테스트판을 찾으려면 **테스트 릴리스 포함**을 켜세요.

## 검증 범위

엔진·클라이언트·업데이트 회귀, 관심명단 파일 왕복, 튜토리얼 상태와 네이티브
레이아웃 및 배포 파일 무결성을 검사합니다. 최종 결과는 배포본의
**docs/RELEASE-QA.json**을 확인하세요.

오프라인 fixture 검증은 실제 FM27 세이브의 쓰기·저장·재로드 성공을 뜻하지
않습니다. 실제 FM27의 관심명단 파일 불러오기와 Xbox/Game Pass 빌드는 별도
확인이 필요합니다. 부상·징계 삭제, 결속력, FM27 스태프 강제이적 등 기존
미지원 기능을 새로 지원하는 버전은 아닙니다.
