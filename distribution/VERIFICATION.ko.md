# 기능별 지원 및 검증 안내

아래 표는 검증 범위를 설명합니다. 이전 0.11.0 연결에서 확인한 결과가
0.12.0 배포판 전체의 검증을 대신하지는 않습니다. 최종 배포에 별도 검증
결과 파일이 있으면 해당 버전·게임 빌드·검사 결과를 함께 확인하세요.

| 기능 | 검증 방법 | FM27의 현재 제한 |
|---|---|---|
| 선수 CA/PA·능력치·히든·포지션 | 조회·유효/오류 미리보기, 오프라인 변경 검증 | 검증된 필드만 노출 |
| 스태프 조회·점수·추천 | 능력치/점수 계산, 검색·상세·추천 조회 | 구형 GK 배급/핸들링 개별 점수 제외 |
| 선수단·연령팀·남축/여축 구분 | 검색/필터/정렬 fixture와 실시간 조회 | 일부 팀은 정확한 명칭 대신 연령팀 번호 표시 |
| 포지션 정렬 | GK→ST 순서 fixture, 검색 화면 검사 | 읽기 기능 |
| 구단·재정·도시 | 조회 및 허용 범위 미리보기 | 도시 인구는 인원수가 아닌 등급, 통화 기준 GBP |
| 기타 인물 | 기본 인물 정보 조회 | 미검증 추가 히든 제외 |
| 대량 편집·고정·복원 | 오프라인 검토/변경/오류복구 fixture | 실게임 쓰기·복원은 배포 시험에 포함하지 않음 |
| 관계·커리어 계획·추가 국적 | FM26 오프라인 구조 및 FM27 차단 검사 | FM27 편집 차단 |
| 후원 이벤트·성장 추정 | 오프라인 도구/검토 및 FM27 차단 검사 | FM27 사용 차단 |
| 계약·건강·선호 플레이 | 엔진 기능 목록에 있는 검증 필드만 표시 | 미검증 FM27 필드 제외 |
| 한글 이름 | 미리보기·설치 경로/복원 fixture | 배포 시험에서 실제 게임 파일 설치하지 않음 |
| 저장/로드 감지 | 세션 무효화·재연결 모의 테스트, 현재 연결 poll | 실제 게임 저장/로드를 시험 목적으로 실행하지 않음 |
| UI·이미지·스냅샷·열 선택 | 오프라인 네이티브 화면 검사 | 개인 스냅샷/초상화는 배포에서 제외 |
| 폴더 배치·실행기 | 전체 파일 해시, 다른 작업 폴더/한글·공백 경로 실행 | ZIP 전체 압축 해제 필요 |

미리보기 성공은 실게임 적용·저장·다시 불러오기까지 성공했다는 뜻이
아닙니다. 지원하지 않는 기능을 실패 없이 차단하는 것도 검증 대상입니다.
게임을 수정하는 시험은 사용자 세이브에 자동으로 수행하지 않습니다.
