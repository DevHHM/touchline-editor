# Touchline Editor 0.12.1

자료실 댓글의 국적 검색과 리그 분류 요청을 반영했습니다.

- **주 국적 검색:** 선수·스태프·기타 인물의 기본 국적을 국가 ID로 필터링합니다. 국가 이름 직접 입력, 목록 선택, 검색 조건 저장·불러오기를 지원합니다.
- **리그·구단:** 국가와 남녀 구분으로 리그를 찾고 소속 구단 상세로 이동할 수 있습니다. 상세에서 돌아와도 필터와 리그 선택을 유지합니다.
- **입력창 표시 수정:** 편집 가능한 선택 상자에 실제 텍스트 입력칸이 표시되도록 수정했습니다.
- **무직 감독 새로고침:** 소속 구단이 없는 감독도 리그 목록과 구단 상세를 새로 읽을 수 있습니다.

ZIP 전체를 새 폴더에 풀고 최상위 `Touchline Editor.exe`를 실행하세요. 기존 앱의 실행파일만 교체하거나 DLL을 따로 옮기지 마세요.

## 확인한 범위

Rust 테스트 284개 통과, 선택 시험 8개 제외. 실제 배포 엔진을 사용한 클라이언트 테스트 165개 통과. 합성 스냅샷으로 국적 검색·저장/복원·검색 열 선택·리그 탐색·상세 왕복·무직 감독 새로고침을 확인했습니다. 작은 창 1120×740과 국적 조건 창 820×620도 확인했습니다.

FM27 리그 연결은 게임 파일의 실제 속성 분기와 객체 구조를 확인한 읽기 전용 경로입니다. 이번 시험에서는 FM이 종료되어 있어 실제 세이브의 리그 목록은 조회하지 않았고, 게임 값 변경·저장·로드도 실행하지 않았습니다. 미확인 리그는 추정하지 않고 별도 그룹에 남깁니다. 국적 검색은 주 국적만 대상이며 추가 국적이나 구단 국가를 뜻하지 않습니다.

이 버전은 관계·커리어 계획·후원 이벤트 등 미지원 FM27 기능의 제한을 해제하지 않습니다. 자세한 범위는 `VERIFICATION.ko.md`를 참고하세요.
