# Touchline Editor 0.14.3 — 종합 실시간 에디터

최근에 열었던 선수와 검색 조건을 다시 찾기 어렵다는 피드백을 반영했습니다. 미배포 상태였던 0.14.2 연결 수정과 관심명단 개선도 함께 포함합니다.

- **최근 기록:** 최근 프로필과 완료한 검색을 각각 20개까지 이 PC에 저장합니다. 같은 항목은 위로 올리며, 메뉴에서 다시 열거나 전체 삭제할 수 있습니다. 연결이나 세이브가 바뀐 뒤 과거 프로필은 이름 검색으로 전환해 현재 자료에서 다시 선택하게 합니다.
- **글자 가독성:** Aa 메뉴에 본문을 두껍게 보는 옵션을 추가했습니다. 선택을 저장하며, 보조 글자 대비와 작은 설명 글자 크기도 개선했습니다. 기존 화면 배율과 회색조/ClearType 선택을 함께 사용할 수 있습니다.
- **적용 안내:** 일반 라이브 수치 수정에는 FM 재시작이 필요 없다는 점을 변경 검토와 완료 안내에 명시했습니다. FM 화면을 다시 열어 확인하고 게임에서 저장하세요. 이름 한글화·초상화 파일 설치는 각 기능의 재로딩 안내를 따릅니다.
- **파일 누락 안내:** 실행 시 필요한 파일이 없으면 누락 목록과 함께 압축 해제 및 보안 프로그램 보호 기록 확인 방법을 표시합니다. 실행 파일이 사라지는 원인을 이번에 확정한 것은 아닙니다.
- **연결 수정:** 진행된 세이브의 인물 목록에 기자가 포함되면 연결이 거절되던 검사를 보완했습니다. 첫 연결과 자동 재연결에 적용되며 미지원 빌드 검증은 유지합니다. 제보자의 실제 세이브에서는 재확인이 필요합니다.
- **관심명단:** 생성·추가·삭제·이름 변경·JSON 가져오기/내보내기, 선수·스태프 FMF 파일 내보내기 및 FMF/SLF/SSF 가져오기를 포함합니다. FM 내부 반영은 게임에서 파일을 불러와야 하며 실제 FM27 가져오기는 추가 확인이 필요합니다.

오류 보고는 **오류 발생 시 사용자가 공유에 동의한 경우에만** 공개 GitHub 이슈로 전송합니다. 최근 프로필·검색 기록이나 세이브 파일을 진단 보고에 추가하지 않았습니다.

부상·징계 제거, 결속력, FM27 스태프 강제이적·취업비자·구단 은퇴 설정, 유소년 양성 기관은 이번에 추가한 기능이 아닙니다. Xbox/Game Pass 실제 빌드 연결과 제보자의 세이브 재현은 미확인입니다.

ZIP 전체를 새 폴더에 압축 해제하고 루트의 `Touchline Editor.exe`를 실행하세요. 자동 업데이트에서는 **테스트 릴리스 포함**을 켜야 이 공개 테스트판을 확인할 수 있습니다.

검증: 오프라인 엔진·클라이언트 회귀, 화면을 띄우지 않는 WPF 배율·가독성 검사, 패키지 버전·무결성 검사를 수행합니다. 사용자 게임을 진행하거나 세이브 값을 수정하지 않습니다.
