# Touchline Editor 0.14.0

## 포지션 검색

- 피치에서 GK부터 ST까지 14개 위치를 직접 선택할 수 있습니다.
- 자연스러움(숙련도 20) 또는 정확한 최소 숙련도 1~19로 검색합니다.
- 여러 위치를 선택하면 그중 하나 이상을 만족하는 선수를 찾습니다. CA·나이 등 다른 조건과 함께 사용할 수 있습니다.
- 피치 선택과 조건 행, 조건 삭제, 저장한 검색 조건의 복원이 서로 동기화됩니다.
- 현재 자료에서 지원하지 않는 위치 값은 임의로 생성하거나 일치 처리하지 않습니다.

## 오류 진단

- 연결 실패·엔진 실행·예외 원인을 정제한 순환 로그로 기록합니다.
- 연결 오류 화면과 F1 도움말에 로그 폴더 열기·진단 ZIP 내보내기를 추가했습니다.
- 명령의 인자와 응답 데이터를 기록하지 않습니다. 개인 경로·토큰·주소를 가립니다.
- 오류 발생 시 **그 보고서를 공유할지 먼저 묻는** 중앙 수집 클라이언트를 추가했습니다. 기본 선택은 ‘공유 안 함’이며, ‘이 오류 공유’를 눌렀을 때 해당 보고서만 공개 GitHub로 보냅니다. 새 오류에는 다시 동의를 받으며, 동일 오류의 반복 동의창은 억제합니다. 앞으로 발생할 오류 전체를 자동 승인하는 설정은 없습니다.
- 전송 주소·개인정보 안내 주소·공개 범위가 바뀌면 다시 동의해야 합니다. 이전 형식의 동의는 자동 승계하지 않습니다.
- 동의 해제 시 진행 중 요청과 새 전송을 즉시 차단합니다. 설정 파일을 읽거나 저장하지 못해도 현재 실행의 전송은 꺼지며, 저장 실패 시 재실행 후 확인이 필요하다고 안내합니다.
- 이미 공개된 보고서는 동의 해제로 자동 삭제되지 않습니다.
- 승인한 오류를 Cloudflare에서 받아 공개 GitHub 이슈로 묶습니다. 같은 보고서를 재전송해도 중복 집계하지 않습니다.

중앙 수집 서버 배포와 합성 보고서의 GitHub 이슈 생성·중복 억제 검증을 완료했습니다.
공유를 거절해도 에디터와 로컬 진단 기능은 계속 사용할 수 있습니다. 자세한 데이터 항목과
보관 기준은 `DIAGNOSTICS.ko.md`를 참고하세요. 서버 인증 토큰은 배포 파일에 포함하지 않습니다.

## 검증

- Rust 전체 테스트: 305개 통과, 실패 0개, 기존 무시 항목 8개.
- 클라이언트 전체 테스트: 오류별 동의 보강 후 309개 통과, 실패 0개.
- 중앙 전송 관련 집중 검사 65개도 모두 통과했습니다. 기본 거절·동의창 실패·동시 오류·늦게 도착한 승인·설정 파일 독점 잠금·해제 저장 실패·동의 범위 변경·취소·중복 억제·전송 제한·변조된 보고 거절을 확인했습니다.
- 격리된 실제 엔진 프로세스에서 합성 요청 5개로 로그 형식·민감값 제외·종료 후 잠금 해제를 확인했습니다.
- 0.14.0 실행용 패키지에서 네이티브 화면과 포지션 14개·복수 위치 OR 검색·숙련도·조건 저장/복원·메뉴 대비·오류 표시를 확인했습니다. 실제 배포 서버 설정을 읽은 배포 DLL의 동의창·진단 도움말도 오프라인으로 확인했으며 이 화면 검사에서 네트워크 요청은 0회였습니다.
- 수집 서버 테스트 20개 통과: 실제 workerd·SQLite 환경과 모의 GitHub 응답을 포함합니다.
- 배포한 서버에 합성 보고서를 두 번 보내 GitHub 이슈 하나·보고 건수 1건으로 처리됨을 확인했습니다.
- 이번 검증에서 게임 데이터는 수정하지 않았고 실제 사용자 로그를 외부에 보내지 않았습니다.

모든 사용자 PC의 연결 성공이나 모든 FM 빌드와의 호환성을 보장하는 것은 아닙니다.
