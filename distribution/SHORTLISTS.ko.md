# 관심명단 사용 방법

검색 결과에서 **관심명단**을 열거나, 스카우팅·대량 편집의 관심명단 탭에서
**FM 명단 관리 · 가져오기/내보내기**를 누르세요.

1. 이름을 입력하고 새 명단을 만듭니다. 검색에서 선택한 대상이 있으면 함께 추가됩니다.
2. 선택한 선수·스태프 또는 완료된 검색 결과 전체를 추가할 수 있습니다.
3. 이름 변경, 선택 대상 제거, 명단 삭제는 Touchline에 즉시 저장됩니다.
4. **FM용 파일 내보내기**로 `.fmf`를 저장합니다. 선수와 스태프는 별도 명단으로 만드세요.
5. FM27의 선수 또는 스태프 관심명단에서 파일 불러오기를 선택해 저장한 파일을 엽니다.

FM 파일 교환은 시험 지원입니다. 파일 구조와 게임 읽기 코드를 대조했지만,
실제 FM27에서 가져오기 성공 여부는 확인이 필요합니다.
게임 메모리에 즉시 반영하거나 자동 동기화하는 기능은 아닙니다.
Touchline에서 삭제한 명단이 FM에서도 자동 삭제되지는 않습니다.

**FM / JSON 명단 가져오기**는 `.fmf`, `.slf`, `.ssf`, `.json`을 읽습니다.
항목 수를 확인하고 가져오면 같은 이름의 명단은 대상을 합치며 중복은 제거합니다.
기존 프리셋은 유지합니다. **JSON 백업**은 Touchline 전용이며 FM에 직접 넣을 수 없습니다.

기존 파일 덮어쓰기는 지원하지 않으므로 내보낼 때 새 이름을 사용하세요.
다른 세이브의 생성 선수는 UID가 달라질 수 있습니다. 연결되지 않은 상태에서는
이름 대신 UID로 표시되며, 확인되지 않은 대상을 자동 삭제하지 않습니다.
