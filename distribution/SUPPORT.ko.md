# 지원 범위와 검증 구분

Touchline은 WPF 데스크톱 UI와 Rust 엔진을 사용하는 Windows x64 앱입니다.
브라우저와 WebView가 필요하지 않으며 .NET/WPF 런타임을 함께 배포합니다.
FM의 설치 파일이나 세이브 데이터는 포함하지 않습니다.

## 포함 기능

- 선수·스태프·구단·기타 인물·도시 검색, 필터, 정렬 및 상세 화면
- 현재 엔진이 제공하는 능력치·계약·관계·커리어 계획 등의 조회·변경 검토
- 스카우팅·대량 편집, 이벤트 도구, 변경 기록, 스냅샷 열기 및 내보내기
- 게임 저장/로드 감지와 연결 갱신, 로컬 API

실제 수정 가능 필드는 연결된 게임 빌드의 기능 목록과 상세 화면을 기준으로
합니다. 모든 FM 버전이나 모든 르테 기능에 대한 호환성을 뜻하지 않습니다.
연결 상태가 읽기 전용이면 수정 가능한 새 세션으로 확인되기 전까지 적용하지
않습니다. 조건이 충족되지 않는 항목은 읽기 전용 또는 비활성으로 표시됩니다.

FM27은 선수·스태프 핵심 능력치/성격/포지션, 검증된 구단 재정·도시 필드와
한글화를 우선 지원합니다. 관계·커리어 계획·국적 추가·후원 이벤트·성장
추정은 아직 차단됩니다. 메뉴가 존재한다고 FM27 편집까지 지원하는 것은
아닙니다. FM26 지원과는 별개이며 `VERIFICATION.ko.md`에서 구분합니다.

## 검증의 의미

배포 검사기는 파일 무결성과 시작 경로를 검사합니다. 자동 테스트는 오프라인
데이터의 계산, 검색, 검토 로직과 화면을 검사할 수 있습니다. 빌드 성공이나
오프라인 검사 통과만으로 모든 게임 빌드의 실시간 쓰기가 검증되었다고
간주하지 않습니다. 배포 과정은 테스트 목적으로 게임 값을 바꾸지 않습니다.

## 설치 문제

- DLL 누락: ZIP 전체를 다시 압축 해제합니다. `app/`·`engine/`을 함께 둡니다.
- 읽기 전용 연결: FM 세이브 로딩 완료 여부와 게임 빌드 지원 상태를 확인합니다.
- 세이브를 다시 불러온 후 오래된 값: 다시 읽기 후 새로운 변경 검토를 만듭니다.
- 이미지가 없음: 이 ZIP은 개인 초상화 팩과 게임 그래픽을 포함하지 않습니다.
- SmartScreen: 이 빌드는 서명 인증서가 없는 개인용 빌드입니다. 출처와 제공된
  SHA-256을 확인하세요. 보안 설정을 전역으로 끄지 마세요.
