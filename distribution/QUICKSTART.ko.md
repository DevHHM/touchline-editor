# Touchline Editor 빠른 시작

ZIP 전체를 새 폴더에 풀고 최상위 **Touchline Editor.exe**를 실행하세요.
실행기는 `app/`의 WPF 화면을 열며, 엔진은 `engine/`에서 찾습니다. 실행
위치와 무관하게 동작하며 한글과 공백이 포함된 폴더도 지원합니다.

## 상세 검색

**검색·필터 → 검색 편집 → 상세 조건**에서 왼쪽 항목을 검색하거나 **조건 추가** 메뉴를 엽니다. 조건마다 사용 여부, 비교 방식, 기준값, 그리고/또는 연결을 정하고 순서를 바꿀 수 있습니다. 선수는 포지션 피치에서 위치와 최소 숙련도를 선택할 수 있습니다. 범위와 숫자 비교는 실제 지원 필드의 최솟값·최댓값을 따릅니다. 데이터가 없는 인물은 해당 숫자 조건에 일치하지 않습니다.

‘그리고’로 이어진 조건을 먼저 묶고 ‘또는’으로 묶음 중 하나를 고릅니다. 기존 기본 조건과 빠른 능력치는 모든 묶음에 적용됩니다. 조건식 아래에 계산 순서가 표시됩니다.

## 관심명단

검색 결과에서 **Ctrl·Shift**로 대상을 여러 명 선택하고 **관심명단**을 여세요.
**새 명단**은 선택한 대상을 함께 저장합니다. 기존 명단에는 검색에서 선택한
대상이나 완료된 검색 결과 전체를 추가할 수 있습니다. 명단에서 여러 명을
선택해 제거하거나, 명단 이름을 바꾸고 삭제할 수도 있습니다. 이 창의 변경은
즉시 저장되며 FM 선수 데이터는 바뀌지 않습니다.

명단은 선수·스태프의 종류와 UID를 기준으로 저장합니다. 같은 대상은 중복
추가되지 않고, 현재 세이브에서 찾지 못한 대상도 자동 삭제하지 않습니다.
선택한 명단을 JSON으로 내보내고 다시 가져올 수 있습니다. **Touchline 전용
명단이며 FM 내부 영입명단이나 `.fmf`·`.slf` 파일과는 호환되지 않습니다.**

스카우팅·대량 편집 창과 같은 명단을 공유합니다. 다른 창에서 먼저 저장했다면
오래된 내용으로 덮어쓰지 않고 다시 읽도록 안내합니다. 대량 편집 창의
**저장본 다시 읽기**로 최신 명단·프리셋을 불러올 수 있습니다.

## CA·PA 숨기기

창 오른쪽 위 **CA·PA 표시**에서 **현재 능력 (CA) 숨기기**, **잠재 능력 (PA) 숨기기**를 각각 켜세요. 설정은 다음 실행에도 유지됩니다. 검색 결과, 선수·스태프 상세, 구단 선수단, 비교, 변경 이력에서 해당 숫자 대신 **숨김**을 표시합니다. 성장 참고치는 CA 또는 PA를 숨기면 함께 가려집니다.

숨긴 능력으로 정렬하거나 검색할 수 없습니다. 이미 저장한 검색 조건과 수정 초안은 유지되며, 숨긴 항목이 들어 있는 조건·수정은 표시를 다시 켜서 확인한 뒤 사용할 수 있습니다. 숨기기는 화면 표시 설정입니다. 원본 스냅샷과 CSV 내보내기에는 CA·PA가 포함될 수 있어 내보내기 전에 안내합니다.

## 업데이트

왼쪽 **업데이트**에서 자동 확인을 끄거나 켜고, 새 버전을 수동으로 확인할 수 있습니다. 다운로드를 선택하면 파일 검증 후 에디터를 정상 종료할 때 설치합니다. 설치 예약을 취소할 수도 있습니다. 세부 절차와 복구 안내는 **UPDATES.ko.md**를 확인하세요.

## 연결과 편집

FM에서 세이브를 불러온 뒤 **FM 다시 연결**을 누릅니다. 엔진이 지원 여부와
현재 세이브를 확인합니다. 지원하지 않는 게임 빌드에서는 쓰기 기능이
제한될 수 있습니다. 스냅샷은 오프라인 조회용이며 실제 게임을 변경하지 않습니다.

선수·스태프·구단·도시 검색 결과에서 대상을 열고, 변경할 값을 입력한 뒤
변경 검토에서 대상과 이전 값·변경 값을 확인하고 적용하세요. 저장/로드로
세이브가 바뀌면 다시 읽은 데이터로 새 검토를 만드세요. 오래된 검토는
현재 세이브에 재사용할 수 없습니다. 게임 내 저장은 FM에서 직접 합니다.

## 창과 검색 단축키

오른쪽 위 **화면 100% → 화면 크기 · 글자와 버튼**에서 80%, 90%, 100%,
110%, 125%, 150%를 선택하세요. 글자와 입력칸·버튼이 함께 바뀌고 다음 실행에도
유지됩니다. **Ctrl + / Ctrl −**로 확대·축소하고 **Ctrl+0**으로 기본 크기로
돌아갑니다. 창이 작거나 Windows 배율이 높아 내용이 들어가지 않으면 화면의
가로·세로 스크롤로 전체 영역에 접근할 수 있습니다. 화면 크기 메뉴는 항상
창 위에 남아 있습니다. 같은 메뉴에서 기존 회색조·ClearType 선명도도 선택합니다.

창 위치·크기·최대화 상태와 왼쪽 목록 폭을 기억합니다. 사용하던 모니터가
분리되면 연결된 모니터 안으로 복원합니다. 검색창 오른쪽 지우기 버튼으로
검색어를 비울 수 있고, 화면 위 `?` 또는 F1에서 단축키를 확인합니다.

| 키 | 동작 |
|---|---|
| Ctrl+F | 검색창으로 이동 |
| Ctrl+Shift+F | 검색·필터 열기 |
| F5 / Ctrl+R | 현재 정보 새로 읽기 |
| Alt+← / Alt+→ | 이전 / 다음 상세 화면 |
| Ctrl+S | 변경 검토 열기 — 즉시 적용하지 않음 |
| F1 | 단축키 안내 |

## 주 국적으로 검색

선수·스태프·기타 인물에서 **새 검색 / 검색 편집**을 열고 **주 국적**에
국가 이름을 입력하거나 목록에서 선택하세요. **모든 국적**으로 되돌리면
국적 제한이 풀립니다. 주 국적은 검색 조건 저장·불러오기에 함께 저장되며,
소속 구단의 국가나 추가 국적을 뜻하지 않습니다.

## 국가·리그에서 구단 찾기

왼쪽 **리그·구단**을 열고 국가 또는 리그 이름으로 범위를 좁히세요.
리그를 선택하면 소속 구단 목록이 나오며, 구단을 열면 선수단·스태프·재정 등
기존 상세 화면으로 이어집니다. **리그 목록으로**를 누르면 탐색 화면으로 돌아옵니다.
남축·여축을 구분할 수 있고 리그 연결이 없는 구단은 **기타 / 리그 미확인**에 남습니다.
현재 읽은 1군 소속 대회 기준이며, 순위표는 아닙니다.

## 배포 파일 검사

PowerShell에서 다음을 실행합니다. 전체 파일의 SHA-256, 누락, 추가 파일,
폴더 구조와 실행기의 경로 검사를 확인하며 게임에는 연결하지 않습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\docs\Verify-Package.ps1
```

일반 설정과 작업 중 생성하는 기록은 사용자 데이터 영역 또는 직접 지정한
위치에 저장됩니다. 문제가 있으면 게임 버전, 재현 단계, 오류 문구를 함께
기록하세요. API 인증 토큰이나 개인 세이브를 공개하지 마세요.

## 선택 기능: 로컬 API

GUI에는 Python이 필요 없습니다. API 클라이언트를 사용할 때만 Python 3을
설치하고 아래 명령을 실행하세요. 서버는 로컬 주소에서만 수신합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\api\start-api.ps1
python .\api\touchline_api.py status
python .\api\touchline_api.py capabilities
```

API 엔진은 `engine/Touchline Engine.exe`입니다. 기존 서버가 실행 중이면
클라이언트가 재사용할 수 있습니다. 새 배포판의 엔진으로 교체하려면 먼저
기존 서버를 종료한 후 실행하세요. 인증 정보는 `%LOCALAPPDATA%\TouchlineEditor`
아래에서 별도로 생성하며 배포 ZIP에는 넣지 않습니다.

## 업데이트

이전 버전을 종료하고 새 ZIP을 다른 폴더에 풀어 실행하세요. 사용 중인
배포 폴더에 DLL을 부분적으로 덮어쓰지 마세요. 이전 폴더는 확인이 끝날
때까지 남겨두면 됩니다. ZIP SHA-256 파일은 배포 시 함께 제공됩니다.
