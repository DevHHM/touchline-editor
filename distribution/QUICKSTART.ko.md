# Touchline Editor 빠른 시작

ZIP 전체를 새 폴더에 풀고 최상위 **Touchline Editor.exe**를 실행하세요.
실행기는 `app/`의 WPF 화면을 열며, 엔진은 `engine/`에서 찾습니다. 실행
위치와 무관하게 동작하며 한글과 공백이 포함된 폴더도 지원합니다.

## 연결과 편집

FM에서 세이브를 불러온 뒤 **FM 다시 연결**을 누릅니다. 엔진이 지원 여부와
현재 세이브를 확인합니다. 지원하지 않는 게임 빌드에서는 쓰기 기능이
제한될 수 있습니다. 스냅샷은 오프라인 조회용이며 실제 게임을 변경하지 않습니다.

선수·스태프·구단·도시 검색 결과에서 대상을 열고, 변경할 값을 입력한 뒤
변경 검토에서 대상과 이전 값·변경 값을 확인하고 적용하세요. 저장/로드로
세이브가 바뀌면 다시 읽은 데이터로 새 검토를 만드세요. 오래된 검토는
현재 세이브에 재사용할 수 없습니다. 게임 내 저장은 FM에서 직접 합니다.

## 창과 검색 단축키

창 위치·크기·최대화 상태와 왼쪽 목록 폭을 기억합니다. 사용하던 모니터가
분리되면 연결된 모니터 안으로 복원합니다. 검색창 오른쪽 지우기 버튼으로
검색어를 비울 수 있고, 화면 위 `?` 또는 F1에서 단축키를 확인합니다.

| 키 | 동작 |
|---|---|
| Ctrl+F | 검색창으로 이동 |
| Ctrl+Shift+F | 검색·필터 열기 |
| F5 / Ctrl+R | 현재 정보 새로 읽기 |
| Alt+← / Alt+→ | 이전 / 다음 상세 화면 |
| Ctrl+S | 변경 검토 열기 — 즉시 적용하지 않음 |
| F1 | 단축키 안내 |

## 배포 파일 검사

PowerShell에서 다음을 실행합니다. 전체 파일의 SHA-256, 누락, 추가 파일,
폴더 구조와 실행기의 경로 검사를 확인하며 게임에는 연결하지 않습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\docs\Verify-Package.ps1
```

일반 설정과 작업 중 생성하는 기록은 사용자 데이터 영역 또는 직접 지정한
위치에 저장됩니다. 문제가 있으면 게임 버전, 재현 단계, 오류 문구를 함께
기록하세요. API 인증 토큰이나 개인 세이브를 공개하지 마세요.

## 선택 기능: 로컬 API

GUI에는 Python이 필요 없습니다. API 클라이언트를 사용할 때만 Python 3을
설치하고 아래 명령을 실행하세요. 서버는 로컬 주소에서만 수신합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\api\start-api.ps1
python .\api\touchline_api.py status
python .\api\touchline_api.py capabilities
```

API 엔진은 `engine/Touchline Engine.exe`입니다. 기존 서버가 실행 중이면
클라이언트가 재사용할 수 있습니다. 새 배포판의 엔진으로 교체하려면 먼저
기존 서버를 종료한 후 실행하세요. 인증 정보는 `%LOCALAPPDATA%\TouchlineEditor`
아래에서 별도로 생성하며 배포 ZIP에는 넣지 않습니다.

## 업데이트

이전 버전을 종료하고 새 ZIP을 다른 폴더에 풀어 실행하세요. 사용 중인
배포 폴더에 DLL을 부분적으로 덮어쓰지 마세요. 이전 폴더는 확인이 끝날
때까지 남겨두면 됩니다. ZIP SHA-256 파일은 배포 시 함께 제공됩니다.
