# Touchline Editor 0.14.1

CA·PA를 보지 않고 선수와 스태프를 살펴볼 수 있도록 표시 옵션을 추가했습니다.

- 상단 **CA·PA 표시** 메뉴에서 현재 능력과 잠재 능력을 각각 숨길 수 있습니다.
- 검색 목록, 상세 정보, 선수 비교, 구단 선수단·스태프, 변경 이력에 함께 적용됩니다.
- 해당 능력의 막대, 복사 값, 툴팁과 성장 참고치도 가려집니다.
- 숨긴 능력의 정렬·검색 조건과 확인할 수 없는 변경 적용을 막습니다. 저장한 조건과 작성 중인 수정 초안은 보존합니다.
- 설정은 앱 재실행 후에도 유지됩니다. 게임 데이터는 변경하지 않습니다.

원본 JSON/CSV 내보내기는 데이터를 보존하며, 숨기기 사용 중에는 CA·PA가 포함된다는 안내를 먼저 표시합니다.

기존 폴더에 덮어쓰지 말고 ZIP 전체를 새 폴더에 풀어 `Touchline Editor.exe`를 실행하세요.
