# Touchline Editor 0.14.6 — 종합 실시간 에디터

처음 실행하는 분들이 버튼 위치와 사용 순서를 바로 알 수 있도록 시작 안내를 바꿨습니다. 계약기간 피드백에 대한 날짜 입력 개선도 함께 담았습니다.

## 달라진 점

- 실제 화면 위에서 연결 → 메뉴 → 검색 → 변경 검토 → 변경 이력 → 도움말의 여섯 위치를 차례로 강조합니다. 강조 테두리와 안내 카드가 다음 버튼으로 부드럽게 이동합니다.
- 다음·이전·건너뛰기와 키보드 조작을 지원합니다. 작은 창이나 화면 확대에서도 안내가 화면 안에 배치되며, Windows 애니메이션 설정을 존중합니다.
- 안내 중에는 실제 연결·변경 적용 버튼이 실행되지 않습니다. 안내를 마치면 원래 스크롤과 포커스로 돌아옵니다.
- 기존 안내를 완료한 이용자는 **도움말 → 처음 시작하기**에서 새 안내를 다시 볼 수 있습니다.
- 선수·스태프 계약 날짜를 `YYYY-MM-DD`로 보고 입력할 수 있도록 정리했습니다. 잘못된 날짜와 시작일·종료일 순서를 검사하고, 원래 값으로 되돌릴 수 있습니다.
- 검증된 FM27 빌드의 기존 고정 계약 종료일 경로를 추가했습니다. 계약 시작일은 추가 조항에 날짜 의존성이 없는 경우에만 편집할 수 있으며, 조건을 충족하지 않으면 읽기 전용으로 표시합니다. FM26은 기존 지원 범위를 유지합니다.

## 다운로드와 실행

Windows 10/11 x64용입니다. `Touchline-Editor-0.14.6-win-x64.zip` 전체를 새 폴더에 풀고 최상위 `Touchline Editor.exe`를 실행하세요. `app`·`engine` 폴더를 함께 두어야 합니다. GitHub의 자동 생성 `Source code` ZIP은 실행 파일이 아닙니다.

기존 앱에서 받으려면 업데이트 설정의 **테스트 릴리스 포함**을 켜세요. 별도 .NET 설치나 브라우저는 필요하지 않습니다.

## 확인한 범위와 제한

튜토리얼은 실제 WPF 컨트롤을 대상으로 네 가지 창 크기·확대율에서 총 24개 배치 사례와 이동 애니메이션, 키보드·포인터 입력 차단, 종료 후 정리를 검사했습니다. 세부 배포 검증 결과는 `docs/RELEASE-QA.json`에 담습니다.

계약 날짜는 코드 경로와 격리된 데이터로 검증했으며 실제 세이브의 쓰기·저장 지속성 검증은 수행하지 않았습니다. 계약 생성, 소속 이동, 옵션·보너스 조항 수정은 이번 변경에 포함하지 않습니다. 지원되는 계약만 필드를 표시합니다.

Game Pass 27.0.0 연결 제보는 계속 확인 중입니다. 해당 배포처의 정확한 실행 파일 검증이 확보되지 않아 이번 버전에서도 지원 완료로 안내하지 않습니다. 다른 빌드·Epic·Mac 지원을 새로 추가한 버전은 아닙니다. FM27 강제이적·부상/징계 삭제 등 미검증 실험 기능도 켜지지 않습니다.

오류 공유는 새 오류마다 전송 내용을 먼저 보여주고 **이용자가 명시적으로 동의한 경우에만** 공개 GitHub 이슈로 전송합니다. 안내를 완료하거나 업데이트했다고 오류 공유에 동의한 것으로 처리하지 않습니다.
