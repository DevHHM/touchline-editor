# Touchline Editor 0.14.5 — 종합 실시간 에디터

자료실·홍보글과 공개 오류 보고에서 확인한 접근성 문제를 수정하고, 반복 요청된 기능의 진입 경로와 사용 안내를 보강한 테스트판입니다.

## 수정한 부분

- 변경 검토 창의 적용·돌아가기 버튼을 스크롤 영역 밖에 고정했습니다. 작은 창에서는 버튼이 줄을 바꾸며 변경 목록만 따로 스크롤됩니다.
- 왼쪽 **능력치 고정**을 추가했습니다. 기존 수치 고정 화면으로 바로 이동하며, 미리보기 없이 자동으로 고정을 시작하지 않습니다.
- 처음 시작하기 안내에서 실제 버튼 이름과 적용 순서를 설명하고, 능력치 고정 화면을 여는 바로가기를 추가했습니다.
- 연결 실패 시 읽은 게임 PE 빌드 코드를 진단 문맥에 유지합니다. 인물·세이브 정보, 메모리 주소와 개인 파일 경로는 이 문맥에 넣지 않습니다. 여러 게임의 빌드가 다르면 하나로 추정하지 않습니다.
- 코드 검증 불일치를 일반 오류와 구분하고, 엔진 파일 누락 안내를 보강했습니다.
- 종료된 엔진을 정리하는 동안 재연결 요청이 겹쳐 엔진이 중복 실행되는 오류를 수정했습니다. 준비·교체·상태 확인을 순서대로 처리하며, 실행 중인 엔진과 결과가 불확실한 변경 요청은 그대로 보존합니다.
- 엔진 연결 종료·통신 실패를 `기타 오류`와 구분합니다. 응답 시간 초과는 시간 초과로 유지하며, Windows 오류 50·500을 접근 거부 오류 5로 잘못 안내하지 않습니다.
- 스냅샷을 열다가 작업 창 닫기를 취소하거나 닫기에 실패하면 기존 FM 연결과 자동 감시를 유지합니다. 취소한 스냅샷 열기 명령은 엔진으로 보내지 않습니다.
- 오류 공유 미리보기와 실제 승인된 전송 내용이 같도록 수정했습니다. 거절한 보고서는 전송하거나 재시도하지 않습니다.

## 능력치 고정 범위

현재 연결한 빌드에서 편집 가능한 수치를 대상으로 합니다. 최대 50명을 검토한 목표 값으로 3초마다 확인하며 작업 창을 닫거나 연결·세이브가 바뀌면 중지합니다. 영구 잠금이나 별도 백그라운드 서비스는 아닙니다.

## 진단 형식

2026-11-01에 기존 형식 1과 확장 형식 2를 함께 받는 수집 서버 배포를 완료하고, 상태 응답과 개인정보 안내를 확인했습니다. 이번 배포 설정은 형식 2를 사용합니다. 형식 2에는 고정된 분류값으로 오류 단계·예외 종류·빌드 출처·알려진 배포처를 담습니다. 관찰한 PE 빌드 식별값은 지원 검증 완료를 뜻하지 않으며, 배포처를 모르면 추정하지 않습니다. 예외 원문·스택·경로는 공개 보고에 포함하지 않습니다. 각 새 오류마다 실제 전송할 전체 내용을 먼저 보여주고 이용자가 명시적으로 동의해야 공개 GitHub 이슈로 수집됩니다. 승인한 미리보기와 보고 ID를 그대로 전송하며, 거절한 보고서는 보내지 않습니다.

## 검증과 남은 작업

엔진·클라이언트 회귀, 실제 WPF의 비표시 배치 검사, 오류 공유 동의·개인정보 제외, 수집 서버의 격리된 저장소·네트워크 검사를 수행했습니다. 배포 파일별 결과는 `docs/RELEASE-QA.json`에 기록합니다. 검사는 게임을 실행하거나 실제 선수·구단 값을 바꾸지 않습니다.

FM27 부상·징계 삭제, 결속력과 선수·스태프 강제이적은 내부 경로를 추가 분석했지만 쓰기·정리·되돌리기 검증이 끝나지 않았습니다. 취업비자·현 구단 은퇴, 대회 교체 규칙, 유소년 생성 전 잠재력 조절과 Mac 대응도 후속 작업입니다. 앱 관심명단 CRUD·JSON 교환은 지원하지만 FMF/SLF/SSF 게임 파일 교환은 시험 지원이며 실제 FM27의 파일 불러오기는 미확인입니다. Xbox/Game Pass·Epic의 다른 빌드는 해당 실행 파일에 맞춘 별도 검증이 필요합니다.

이 버전이 원인이 확인되지 않은 모든 충돌을 해결했다는 뜻은 아닙니다. 단계와 예외 종류가 없던 기존 집계만으로는 개별 원인을 확정할 수 없어 새 진단으로 후속 제보를 구분합니다.
