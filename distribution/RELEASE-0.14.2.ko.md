# Touchline Editor 0.14.2 — 종합 실시간 에디터

진행한 세이브에서 연결되지 않는다는 제보를 조사해, 정상 인물 유형을 연결 검사에서 누락한 문제를 수정했습니다.

## 연결 오류 수정

- FM27 인물 목록에 기자가 포함되면 `인물 레지스트리 객체 유형이 다릅니다` 오류로 연결이 거부될 수 있던 코드를 수정했습니다.
- 첫 연결과 자동 재연결에 같은 수정이 적용됩니다. 게임 빌드·객체 검증은 유지합니다.
- 제보자의 실제 세이브에서는 아직 재확인하지 못했습니다. 모든 연결 실패가 해결됐다는 의미는 아닙니다.
- 수동 연결과 자동 감시의 FM 실행 파일 탐지를 통일하고, 미지원 빌드 안내를 보강했습니다. 실제 Xbox/Game Pass 빌드 호환은 미확인입니다.

## 관심명단·화면 개선

- 검색 결과에서 관심명단 생성, 대상 추가·제거, 명단 삭제·이름 변경, JSON 가져오기·내보내기를 지원합니다.
- 선수·스태프 명단의 FMF 파일 내보내기와 FMF/SLF/SSF 가져오기를 시험 지원합니다. FM 반영은 게임에서 파일 불러오기를 해야 하며, 실제 FM27 파일 불러오기 성공 여부는 추가 확인이 필요합니다. 자동 동기화는 하지 않습니다.
- 화면 배율 80–150%, 배율 단축키와 설정 저장, 작은 창 스크롤을 개선했습니다.
- FM27 선수 사기(0–20) 편집을 변경 검토 경로에 추가했습니다. 부상·징계 제거와 결속력 변경은 포함하지 않습니다.
- 기존 CA·PA 개별 숨김, 상세 검색, 자동 업데이트 기능을 유지합니다.

## 오류 공유와 설치

오류 보고는 **오류가 발생할 때 사용자가 공유에 동의한 경우에만** 공개 GitHub 이슈로 전송합니다. 동의하지 않아도 프로그램을 이용할 수 있습니다. 세이브 파일은 전송하지 않습니다.

ZIP 전체를 새 폴더에 압축 해제하고 `Touchline Editor.exe`를 실행하세요. 기존 폴더에 일부 파일만 덮어쓰지 마세요. 자동 업데이트에서는 **테스트 릴리스 포함**을 켜야 이 공개 테스트판을 확인할 수 있습니다.

검증 범위: Rust·WPF 클라이언트·업데이트 도우미의 오프라인 회귀 검사와 배포 파일 무결성 검사를 수행합니다. 이번 배포 검증을 위해 사용자 게임을 진행하거나 세이브를 수정하지 않습니다. 세부 결과는 배포의 검증 안내를 참고하세요.
