# Touchline Editor 0.12.0

Football Manager의 선수·스태프·구단·도시 정보를 조회하고, 지원되는 수치를 수정하는 **Windows 네이티브 에디터**입니다. Rust 엔진과 C# / WPF 화면으로 만들었으며 한국어 UI와 Pretendard 글꼴을 제공합니다.

**FM27 초기 지원 테스트 배포입니다.** FM26과 FM27을 구분하며, 아래에 명시된 범위를 넘어 모든 FM 버전이나 모든 편집 기능을 지원하는 것은 아닙니다.

## 다운로드

- [Windows x64 실행용 ZIP](https://github.com/DevHHM/touchline-editor/releases/download/v0.12.0/Touchline-Editor-0.12.0-win-x64.zip)
- [릴리스 설명·SHA-256·소스 ZIP](https://github.com/DevHHM/touchline-editor/releases/tag/v0.12.0)
- [문제 제보](https://github.com/DevHHM/touchline-editor/issues)

일반 사용자는 **win-x64.zip**을 받으세요. GitHub의 자동 생성 `Source code` 압축파일은 실행용 프로그램이 아닙니다.

## 실행

1. 편집할 세이브를 따로 백업하고, FM에서 불러옵니다.
2. ZIP 전체를 새 폴더에 압축 해제합니다.
3. 최상위 **Touchline Editor.exe**를 실행하고 **FM 연결**을 누릅니다.
4. 선수·스태프·구단·도시를 검색하고 상세 화면에서 정보를 확인합니다.
5. 수정할 때는 **변경 검토 → 이전/새 값 확인 → 적용** 순서로 진행합니다.
6. 변경 내용을 세이브에 남기려면 FM에서 직접 저장합니다.

`app/`, `engine/`, `api/`, `docs/`, `licenses/` 폴더를 함께 유지하세요. .NET 실행 환경이 포함되어 있으며 GUI 실행에 Chrome, WebView2, Python, AI API는 필요하지 않습니다. 게임 설치 파일이나 세이브는 포함하지 않습니다.

## 주요 기능

- 선수 CA·PA, 능력치·히든 등 지원 필드 조회 및 검토 후 편집
- 스태프 능력치와 직무별 점수, 구단 스태프 비교·교체 후보 검토
- 구단 재정·시설과 도시의 지원 필드 조회·편집
- 이름·UID·수치 조건 검색, 국적 및 사용자 선택 열, 남녀축구 구분
- 1군·유소년 등 실제 소속 선수단 구분, GK→ST 포지션 순서 정렬
- 이름 복사, 프로필 간 링크 이동, 선수 비교, 대량 변경 미리보기
- 변경 이력과 조건부 되돌리기, 저장한 스냅샷의 오프라인 조회
- 선수명 한글화 LNC 파일 설치 도구와 선택형 로컬 API

사진과 로고는 사용자가 설치한 FM 그래픽 팩에서 읽습니다. 스태프 점수는 자체 비교 기준이며 실제 채용 의사나 협상 결과를 보장하지 않습니다. **CA는 개별 능력치를 수정해도 자동 계산되지 않습니다.**

## FM27 지원 범위

현재 확인한 FM27 Windows 빌드 식별자는 **`6ADFB11C-19E69000`**입니다. 게임 업데이트로 구조가 달라지면 재검증이 필요합니다.

FM27에서 **관계·커리어 계획·추가 국적 편집, 후원 이벤트, 성장 추정**은 아직 지원하지 않습니다. 미검증 계약·건강·선호 플레이 필드 및 기타 인물의 성격 편집도 지원 대상에서 제외됩니다. FM26용 기능이 보이더라도 현재 연결의 지원 상태에 따라 차단될 수 있습니다.

## 검증 범위

0.12.0 배포 엔진의 Rust 테스트 272개, 데스크톱 클라이언트 테스트 140개, Python API 클라이언트 테스트 14개가 통과했습니다. 별도로 FM27 실제 세이브의 읽기·미리보기 16개 기능군과 네이티브 화면을 확인했습니다.

실게임 검사는 **게임 값을 쓰지 않고** 수행했습니다. 실제 세이브의 모든 적용·되돌리기·저장 후 재로딩 조합을 검증한 것은 아닙니다. 미지원 기능은 이유를 표시하고 차단합니다. 상세 결과는 실행용 ZIP의 `docs/검증결과.ko.md`를 참고하세요.
